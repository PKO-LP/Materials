# Самопроверка после запуска

Сначала подготовьте выбранный пример по его README: свой settings.py, своя база, таблицы и начальные записи.

## 1. Клуб читателей

- Пустой или неверный код не открывает новое окно.
- Код **Club2026!** открывает список из трёх книг.
- «Обновить список» не дублирует строки.
- Кнопка «Выйти» и крестик возвращают окно входа.

## 2. Список дел

- Пустая задача не сохраняется.
- Новая задача появляется в таблице и остаётся после перезапуска.
- Повтор той же задачи даёт предупреждение.
- «Очистить виджет» убирает только отображение; «Показать все» снова получает записи из БД.

## 3. Расписание кружков

- Понедельник — два кружка, Среда — один, Пятница — пустой результат.
- «Все кружки» возвращает полный список.
- Текст вводится так же, как в начальных данных: например, Понедельник с заглавной буквы.

## 4. Рейтинг команд

- Порог 8 оставляет три начальные команды.
- Кнопки полного списка выводят баллы по возрастанию и по убыванию.
- abc и отрицательное число дают предупреждение, а не закрывают программу.

## 5. Карточка курса

- Python показывает имя Анна, SQL — Борис.
- Название, которого нет в базе, даёт сообщение «Такого курса нет».
- Ответ появляется в Label, а не в таблице.

## 6. Журнал посещений

- Новое учебное имя сохраняется с сегодняшней датой вашего компьютера.
- Повтор этого имени в тот же день даёт предупреждение.
- После перезапуска запись остаётся в журнале.

## 7. Абонементы

- Максимальная сумма 500,50 показывает два начальных абонемента.
- Сумма 0 показывает только «Пробный».
- abc, отрицательная сумма и 12.345 дают предупреждение.
- Кнопки полного списка сортируют все абонементы, независимо от введённой суммы.

## 8. Календарь

- 2026-10-30 — два события, 2026-11-01 — одно.
- Дата без событий даёт пустую таблицу.
- Несуществующая дата 2026-02-30 даёт предупреждение.

Начальные результаты относятся к данным из 02_seed.sql. Если вы добавили записи или изменили данные вручную, результат может отличаться — проверьте его запросом в pgAdmin.

## Если не запустилось

- Нет settings — скопируйте settings_example.py в settings.py рядом с app.py.
- Нет psycopg — проверьте библиотеку в том Python, которым запускаете файл.
- Ошибка подключения — проверьте запуск PostgreSQL и свои настройки сервера.
- База не найдена — выполните 00_create_database.sql в postgres.
- Таблица не найдена — выполните 01_tables.sql в правильной базе.
- Данных нет — выполните 02_seed.sql и проверьте 03_check.sql.
