# Несколько полей: текст, сумма, целое и дата

## Подготовка

1. Скачайте актуальный репозиторий. Если он уже клонирован, выполните `git pull` в папке Materials. Без Git можно заново скачать Code → Download ZIP.
2. В этой папке скопируйте settings_example.py в settings.py. Впишите свой пароль PostgreSQL, проверьте user, host и port.
3. В Query Tool базы postgres отдельно выполните 00_create_database.sql, включив Auto commit, если базы ещё нет.
4. Откройте новый Query Tool базы **mini_member_form**. Выполните 01_tables.sql, затем 02_seed.sql.
5. Откройте терминал в этой папке: `python3 app.py` (либо python app.py, если ваша команда называется python).

## Что показывает

Пять полей одной анкеты сохраняются одним INSERT. Здесь нет входа, товаров, магазина или фильтра. Пример нужен, чтобы увидеть совместное чтение нескольких Entry, разные типы значений и порядок параметров.

## Проверьте

Введите вымышленное имя, группу, сумму 123,45, баллы 0 и существующую дату ГГГГ-ММ-ДД. После «Сохранить анкету» запись появится в Treeview. Закройте окно и откройте заново: она остаётся в БД. Повтор имени в той же группе отклоняется.

Пустое имя, сумма 0, abc вместо баллов, отрицательные баллы и дата 2026-02-30 не сохраняются. При ошибке ввода поля не очищаются.

## Ключевые строки

- `поля` — список Entry. Цикл создаёт пять похожих пар «подпись + поле», enumerate даёт номера строк от 0.
- `поле_имени, ... = поля` даёт каждому из пяти Entry отдельное имя.
- `get()` всегда читает текст. Decimal превращает сумму в число с копейками; int — баллы в целое; date.fromisoformat — текст в дату.
- `данные = (имя, группа, сумма, баллы, дата)` — пять значений в порядке пяти столбцов INSERT. Пять %s получают их из второго аргумента execute.
- Пара «имя + группа» — составной ключ. Его повтор приводит к UniqueViolation.
- Успешный выход из with сохраняет INSERT. Только после этого новый SELECT обновляет Treeview. Напрямую содержимое Entry в таблицу не добавляется.
- При сбое повторного чтения запись уже может быть сохранена. Повторите «Показать», а не вставку.
- Полученные из БД сумма и дата форматируются только для вывода: два знака после точки и ISO-дата.

Подробности CHECK, btrim и составного ключа — в [SQL-памятке](../SQL_памятка/README.md).
