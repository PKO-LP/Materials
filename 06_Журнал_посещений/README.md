# Журнал: одно поле и автоматическая дата

## Что показывает

Пользователь вводит только одно имя. Второе значение для БД — date.today — вычисляет программа. Показывает DATE и составной первичный ключ без второй строки ввода.

В интерфейсе только **одно поле ввода**. Это самостоятельный маленький пример, без подключения к магазину и его таблицам. Собственных классов нет.

## На ноутбуке преподавателя

База `mini_visits` уже подготовлена. Запустите `ЗАПУСТИТЬ.command` двойным щелчком или выполните `python3 app.py` из этой папки.

## На другом компьютере

1. Проверьте Python, Tkinter и Psycopg.
2. Скопируйте settings_example.py в settings.py в этой папке. Укажите параметры своего PostgreSQL.
3. В Query Tool базы postgres отдельно выполните 00_create_database.sql с включённым Auto commit, только если базы ещё нет.
4. В новом Query Tool созданной базы выполните 01_tables.sql, затем 02_seed.sql.
5. Запустите app.py. Для Windows при необходимости замените python3 на python.
6. Для проверки данных используйте 03_check.sql: запросы запускайте отдельно.

Не устанавливайте Psycopg при каждом запуске. При необходимости пакет: `python3 -m pip install "psycopg[binary]>=3.2,<4"`.

## Что попробовать

Отметьте новое вымышленное имя. Дата должна совпасть с сегодняшней датой компьютера. Повтор в этот же день даёт предупреждение.

## Как читать код

Сначала импорты, затем функции кнопок, затем создание окна. Функции могут быть написаны раньше виджетов: они обращаются к ним при нажатии кнопки, когда окно уже создано. Последняя строка mainloop запускает обработку действий. Имена функций в command передаются без скобок.

## Что остаётся студенту

Объяснить путь введённого значения до SQL и результата до виджета. Изменить подпись, условие или порядок вывода. Самостоятельно применить один приём в своей системе. Здесь нет полного решения магазина, нескольких его таблиц или универсальной готовой системы на все случаи.
