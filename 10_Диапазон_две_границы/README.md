# Отбор по двум ценам и сортировка

## Подготовка

1. Скачайте актуальный репозиторий. Если он уже клонирован, выполните `git pull` в папке Materials. Без Git можно заново скачать Code → Download ZIP.
2. В этой папке скопируйте settings_example.py в settings.py. Впишите свой пароль PostgreSQL, проверьте user, host и port.
3. В Query Tool базы postgres отдельно выполните 00_create_database.sql, включив Auto commit, если базы ещё нет.
4. Откройте новый Query Tool базы **mini_price_range**. Выполните 01_tables.sql, затем 02_seed.sql.
5. Откройте терминал в этой папке: `python3 app.py` (либо python app.py, если ваша команда называется python).

## Что показывает

Два Entry «От» и «До» передают два параметра в BETWEEN. Обе кнопки направления применяют введённый диапазон. «Все» очищает границы. Пример только читает мастер-классы; добавления и входа здесь нет.

## Проверьте

- От=250, До=1000: четыре записи; при обратной сортировке те же строки в другом порядке.
- От=750, До=750: одна запись, границы включены.
- Обе границы пустые: весь список.
- Пустое «От»: от нуля. Пустое «До»: до максимально допустимой суммы.
- От=1000, До=250, abc, NaN или отрицательная сумма: предупреждение; старый результат не стирается.
- Подходит запятая 500,50; более двух значащих знаков после точки не допускается.

## Ключевые строки

`WHERE fee BETWEEN %s AND %s` содержит два маркера. `(нижняя, верхняя)` передаёт их значения в том же порядке. Не вставляйте цену f-строкой и не ставьте кавычки вокруг %s.

`False` выбирает ASC, `True` — DESC. Направление сортировки — заранее заданный SQL, а не пользовательское значение для %s. При одинаковой цене второй критерий title задаёт порядок по названию.

Сначала fetchall получает строки, после успешного чтения очищаем Treeview и вставляем их. Поэтому повтор кнопки не удваивает результат, а ошибка не стирает прежний список.
