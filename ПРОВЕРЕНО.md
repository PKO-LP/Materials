# Проверено на ноутбуке — 30 октября 2026 года

Использованы настоящий PostgreSQL 18 на localhost:5432, Psycopg 3 и виджеты Tkinter. Для восьми примеров созданы восемь отдельных учебных баз; SQL создания баз, таблиц и начального заполнения выполнен из файлов комплекта. Основной магазин не изменялся.

Проверены все восемь приложений:

1. Клуб: пустой и неверный код не открывают окно; Club2026! открывает Toplevel, скрывает главное окно и получает три книги из PostgreSQL. Повторное чтение не дублирует строки. Выход и обработчик крестика возвращают главное окно.
2. Задачи: пустое поле отклоняется; новое значение с апострофом сохраняется; повтор отклоняется; очистка и повторный SELECT возвращают сохранённую запись.
3. Кружки: Понедельник — два результата, Среда — один, Пятница — пусто; полный список возвращается кнопкой.
4. Рейтинг: верные ASC/DESC; порог 8 даёт три строки; abc, отрицательное число и переполнение INTEGER отклоняются без очистки прежнего результата.
5. Карточка курса: Python → Анна, SQL → Борис; неизвестное название даёт отдельное сообщение в Label.
6. Посещения: имя сохраняется с реальной сегодняшней датой; повтор имени за день отклоняется.
7. Абонементы: 500,50 даёт два результата; 0 — один; NaN, отрицательная сумма, лишние копейки и буквы отклоняются; полные сортировки дают правильный порядок.
8. Календарь: корректная дата даёт два или одно событие; дата без событий даёт пусто; несуществующая дата отклоняется.

В табличных примерах дополнительно проверена ошибка подключения: прежние строки остаются. Запущен настоящий mainloop одного приложения с автоматическим закрытием пробного окна. В остальных функциональных испытаниях окна создавались реально, события обрабатывались через update, кнопки вызывались программно. Всплывающие сообщения перехватывались, чтобы не требовать ручного закрытия каждого диалога. Это не полная ручная проверка на всех операционных системах.

Созданные тестом случайные задачи и посещения удалены после проверки. Начальные демонстрационные записи сохранены.
