# Учебные материалы: восемь самостоятельных мини-систем

Короткие примеры Python + Tkinter + PostgreSQL. Каждый запускается отдельно, использует свою БД и показывает один или несколько приёмов. Собственных классов нет. Все примеры проверены на PostgreSQL 18 и Python 3.13; подробности — в [отчёте проверки](ПРОВЕРЕНО.md).

## Что изучать

1. **[Клуб читателей](01_Клуб_читателей/README.md)** — вход по одному коду, переход в новое окно, загрузка списка книг и возврат назад.
2. **[Список дел](02_Список_дел/README.md)** — ввод одной записи, сохранение в PostgreSQL и обновление Treeview. Проверка пустого ввода и повторов.
3. **[Расписание кружков](03_Расписание_кружков/README.md)** — поиск по тексту: вводишь день недели, получаешь подходящие кружки.
4. **[Рейтинг команд](04_Рейтинг_команд/README.md)** — отбор по минимальному баллу и сортировка по возрастанию или убыванию.
5. **[Карточка курса](05_Карточка_курса/README.md)** — поиск одной записи через `fetchone()`, вывод ответа в надпись Label.
6. **[Журнал посещений](06_Журнал_посещений/README.md)** — сохранение имени с автоматической сегодняшней датой, проверка повтора за день.
7. **[Абонементы](07_Абонементы/README.md)** — работа с ценой через Decimal, отбор «не дороже» и сортировка стоимости.
8. **[Календарь](08_Календарь/README.md)** — ввод даты, проверка её правильности и поиск событий этого дня.

В интерфейсе каждого примера одно поле ввода. В клубе это общий учебный код, в других примерах — текст, число, цена или дата. Клуб использует код **Club2026!**; это демонстрационный доступ, не личная учётная запись.

## Как начать на своём компьютере

1. Скачайте репозиторий и распакуйте его. Выберите одну папку примера, прочитайте её README.
2. Проверьте Python и Tkinter: `python3 --version`, затем `python3 -m tkinter`. Закройте демонстрационное окно.
3. Проверьте Psycopg: `python3 -c "import psycopg; print(psycopg.__version__)"`. Только если библиотека отсутствует, выполните из корня `python3 -m pip install -r requirements.txt`.
4. В выбранной папке **скопируйте settings_example.py под именем settings.py**. В копии укажите свой пароль PostgreSQL и при необходимости измените host, port, user. Файла settings.py с чужим паролем в репозитории нет; в .gitignore он исключён из публикации.
5. Через pgAdmin откройте Query Tool базы postgres. Выполните `00_create_database.sql` выбранного примера отдельно с включённым Auto commit, только если такой базы ещё нет.
6. Откройте новый Query Tool созданной базы. Выполните сначала `01_tables.sql`, затем `02_seed.sql` из той же папки.
7. Откройте терминал в папке выбранного примера и выполните `python3 app.py`. Для проверки записей используйте `03_check.sql` в pgAdmin.
8. Если подготовили несколько примеров, из корня можно запустить `python3 Открыть_пример.py` и выбрать нужный номер.

На Windows команда может называться `python` вместо `python3`: используйте одно и то же имя при установке и запуске. Файлы .command предназначены для macOS, они не заменяют установку Python и заполнение settings.py.

## Подготовить все восемь примеров

Сначала создайте settings.py из settings_example.py **в каждой** папке и заполните свои параметры. Затем из корня выполните `python3 Подготовить_все_БД.py`. Нужны права PostgreSQL на создание баз. Скрипт добавляет отсутствующие базы, таблицы и начальные строки; существующие данные не удаляет.

## Как использовать на занятии

Запустите один пример → объясните действие одной кнопки → измените одно значение → проверьте результат. Не объединяйте восемь app.py копированием подряд: это разные самостоятельные программы. Перенесите только нужный приём в свой проект.

Учебные базы независимы от основного задания магазина. Преподавательские настройки подключения и готовое решение основного задания здесь не публикуются.
