# Рейтинг: одно число и сортировка

## Что показывает

Один Entry для минимального балла; два столбца вывода. Можно отдельно отобрать по числу или показать весь рейтинг в нужном порядке. Кнопки «Все…» показывают полный список, независимо от введённого порога.

В интерфейсе только **одно поле ввода**. Это самостоятельный маленький пример, без подключения к магазину и его таблицам. Собственных классов нет.

## Подготовка на своём компьютере

Сначала [скачайте проект и проверьте Python, Tkinter и Psycopg](../README.md). Затем откройте эту папку примера.

1. Скопируйте **settings_example.py** в этой папке под именем **settings.py**. Исходный образец удалять не нужно.
2. Откройте settings.py. Укажите свой пароль PostgreSQL; проверьте user, host и port. Для этого примера dbname должен быть **mini_teams**.
3. В pgAdmin откройте Query Tool базы **postgres**, включите Auto commit и отдельно выполните **00_create_database.sql**. Если база mini_teams уже есть, этот шаг пропустите.
4. Выберите базу **mini_teams** и откройте для неё **новый Query Tool**.
5. Выполните **01_tables.sql**, затем **02_seed.sql**. Так вы создадите таблицы и начальные записи на своём сервере.
6. Выполните запросы **03_check.sql** по одному. Это проверка данных до запуска окна.
7. Откройте терминал в этой папке, рядом с app.py, и запустите:

```bash
python3 app.py
```

Если ваша команда Python называется python, используйте `python app.py`. На macOS после подготовки базы и settings.py можно запустить ЗАПУСТИТЬ.command двойным щелчком. Повторять создание базы перед каждым запуском не требуется.

## Что попробовать

Порог **8**: три команды. **abc** и **-1**: предупреждение. Проверьте оба порядка; при одинаковом балле команды идут по названию.

## Как читать код

Сначала импорты, затем функции кнопок, затем создание окна. Функции могут быть написаны раньше виджетов: они обращаются к ним при нажатии кнопки, когда окно уже создано. Последняя строка mainloop запускает обработку действий. Имена функций в command передаются без скобок.

## Что остаётся студенту

Объяснить путь введённого значения до SQL и результата до виджета. Изменить подпись, условие или порядок вывода. Самостоятельно применить один приём в своей системе. Здесь нет полного решения магазина, нескольких его таблиц или универсальной готовой системы на все случаи.
