# SQL: слова и проверки, которые используются в примерах

Эти четыре маленьких SQL-файла можно выполнить отдельно в Query Tool любой своей учебной базы. Таблицы создавать не нужно.

## length

`length(текст)` считает символы. В 01_length.sql ответ 5: четыре буквы и пробел. Поэтому в форме логин сначала обрабатывается strip(), если крайние пробелы не нужны.

`CHECK (length(login) BETWEEN 3 AND 30)` разрешает логин длиной от 3 до 30 включительно. `CHECK` — правило проверки на стороне БД; `BETWEEN ... AND ...` — диапазон с двумя границами.

## btrim и пустая строка

`btrim(текст)` убирает обычные крайние пробелы. `''` — пустой текст. `<>` означает «не равно». Поэтому `CHECK (btrim(member_name) <> '')` отклоняет пустое имя и строку из одних пробелов.

`NOT NULL` запрещает отсутствие значения, но само по себе не запрещает пустую строку. Для непустого имени нужно отдельное CHECK.

## Ключи и обязательные значения

`PRIMARY KEY` — уникальный непустой ключ. В примере регистрации ключ — один login. В анкете `PRIMARY KEY (member_name, group_name)` — уникальна пара: одно имя в разных группах допустимо, одинаковая пара не повторяется.

`public` — схема, раздел внутри базы. Точка отделяет её от имени таблицы. `demo_profiles` — одно выбранное имя; подчёркивание просто соединяет слова.

`CREATE TABLE IF NOT EXISTS` — создать таблицу, если её ещё нет. Уже существующую структуру эта команда не исправляет.

## Типы

- TEXT — текст; в Python str.
- INTEGER — целое; в Python int.
- NUMERIC(10,2) — десятичное число: 10 цифр всего, 2 после точки; в Python Decimal.
- DATE — дата без времени; в Python date.

## Параметры Psycopg

`%s` применяется в строке SQL внутри Python для значения. Сами значения передаются вторым аргументом execute, не подставляются f-строкой. Для одного параметра нужен `(значение,)`, для двух — `(от, до)`. В Query Tool вместо %s пишут конкретные значения.

Имена таблиц, столбцов и ASC/DESC не заменяют через %s. В наших примерах направление сортировки выбирается из двух заранее написанных строк.

## Какие запросы нужны для основных приёмов

- Создать базу — CREATE DATABASE.
- Создать структуру — CREATE TABLE, типы, PRIMARY KEY, NOT NULL, CHECK.
- Сохранить запись — INSERT INTO ... VALUES.
- Найти пользователя или запись — SELECT ... FROM ... WHERE ... = ... .
- Отобрать диапазон — WHERE ... BETWEEN ... AND ... .
- Упорядочить — ORDER BY ... ASC или DESC.
- Посчитать записи — SELECT COUNT(*) FROM ... .

Для этих приёмов не нужны JOIN, вложенные запросы, UPDATE или DELETE. Подробные примеры — в соответствующих папках, не в одном общем готовом решении.
