# 1. База и настройки

Все команды терминала выполняйте из папки testing_app. SQL выполняйте в Query Tool pgAdmin. Код Python пишите в редакторе.

## Проверка установленного

Выполняйте отдельно:

```sh
python3 --version
```

Покажет версию Python.

```sh
python3 -m tkinter
```

Откроет тестовое окно: закройте его. Если модуля нет, нужна установка Python с Tcl/Tk.

```sh
python3 -c "import psycopg; print(psycopg.__version__)"
```

Если psycopg уже есть, устанавливать повторно не нужно. Если отсутствует:

```sh
python3 -m pip install "psycopg[binary]>=3.2,<4"
```

## Файлы настроек

Скопируйте settings_example.py в свою папку и создайте его копию с именем settings.py. В копии замените ВАШ_ПАРОЛЬ своим паролем PostgreSQL. Образец удалять не требуется. Импорт from settings import DB обращается именно к settings.py.

DB — словарь настроек: dbname — имя базы, user — пользователь PostgreSQL, password — его пароль, host — адрес сервера, port — порт, connect_timeout — ожидание соединения в секундах. options ограничивает время SQL-команды пятью секундами. Пароль сервера отличается от паролей пользователей приложения.

Скопируйте password_tools.py в эту же папку. Функции создать_хеш и проверить_пароль уже готовы. Не храните пароль пользователя открытым текстом.

## Создаём отдельную базу

В Query Tool базы postgres выполните один раз:

```sql
CREATE DATABASE final_up_shared;
```

CREATE — создать; DATABASE — базу данных; final_up_shared — её имя. Обновите список баз и откройте Query Tool именно этой новой базы. Если она уже существует, повторное создание пропустите.

Проверьте:

```sql
SELECT current_database();
```

Ответ должен быть final_up_shared. Затем выполните следующие команды по одной, целиком от CREATE до точки с запятой.

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    full_name TEXT NOT NULL CHECK (btrim(full_name) <> ''),
    login TEXT NOT NULL CHECK (length(login) BETWEEN 3 AND 50),
    password_hash TEXT NOT NULL,
    role TEXT NOT NULL CHECK (role IN ('Ученик','Преподаватель'))
);
```

```sql
CREATE UNIQUE INDEX IF NOT EXISTS users_login_lower_unique ON users (lower(login));
```

```sql
CREATE TABLE IF NOT EXISTS questions (
    id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    position INTEGER UNIQUE NOT NULL CHECK (position BETWEEN 1 AND 5),
    question_text TEXT NOT NULL CHECK (btrim(question_text) <> ''),
    option_1 TEXT NOT NULL CHECK (btrim(option_1) <> ''),
    option_2 TEXT NOT NULL CHECK (btrim(option_2) <> ''),
    option_3 TEXT NOT NULL CHECK (btrim(option_3) <> ''),
    option_4 TEXT NOT NULL CHECK (btrim(option_4) <> ''),
    correct_option INTEGER NOT NULL CHECK (correct_option BETWEEN 1 AND 4)
);
```

```sql
CREATE TABLE IF NOT EXISTS attempts (
    id UUID PRIMARY KEY,
    student_id INTEGER NOT NULL REFERENCES users(id),
    finished_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    correct_count INTEGER NOT NULL CHECK (correct_count BETWEEN 0 AND 5),
    grade INTEGER NOT NULL CHECK (grade BETWEEN 2 AND 5)
);
```

```sql
CREATE TABLE IF NOT EXISTS answers (
    attempt_id UUID NOT NULL REFERENCES attempts(id),
    question_id INTEGER NOT NULL REFERENCES questions(id),
    position INTEGER NOT NULL CHECK (position BETWEEN 1 AND 5),
    question_text TEXT NOT NULL,
    option_1 TEXT NOT NULL,
    option_2 TEXT NOT NULL,
    option_3 TEXT NOT NULL,
    option_4 TEXT NOT NULL,
    chosen_option INTEGER NOT NULL CHECK (chosen_option BETWEEN 1 AND 4),
    correct_option INTEGER NOT NULL CHECK (correct_option BETWEEN 1 AND 4),
    PRIMARY KEY (attempt_id,position)
);
```

## Что получилось

users — пользователи с ФИО, логином, защищённым паролем и ролью. questions — пять общих вопросов; четыре варианта хранятся в четырёх текстовых столбцах этой же таблицы, поэтому для чтения вопроса не нужно соединение таблиц. attempts — завершённые попытки. answers — пять сохранённых ответов со снимками текстов и вариантов каждой попытки.

INTEGER — целое число, TEXT — текст. GENERATED ALWAYS AS IDENTITY автоматически выдаёт новый числовой ID. PRIMARY KEY — уникальный идентификатор строки; FOREIGN KEY через REFERENCES связывает запись с существующей записью другой таблицы. Например, student_id ссылается на users(id). Составной PRIMARY KEY (attempt_id,position) запрещает второй ответ на тот же номер вопроса внутри одной попытки.

NOT NULL запрещает отсутствие значения. CHECK проверяет условие. btrim убирает пробелы по краям; <> означает «не равно», '' — пустая строка; BETWEEN включает обе границы; IN перечисляет допустимые значения. position — номер вопроса 1–5, correct_option — правильный вариант 1–4.

CREATE UNIQUE INDEX с lower(login) запрещает логины, отличающиеся только регистром. UNIQUE у номера вопроса запрещает два вопроса с одним номером. IF NOT EXISTS позволяет пропустить уже созданную таблицу/индекс, но не переделывает её структуру.

UUID — уникальный идентификатор попытки, создаваемый uuid4() в Python. Он создаётся один раз при начале и не меняется при повторном нажатии завершения. TIMESTAMPTZ хранит дату и время с часовым поясом; DEFAULT CURRENT_TIMESTAMP подставляет время сохранения. В интерфейсе переводим его в UTC+3.

Скобки после имени таблицы содержат описание столбцов, запятые разделяют столбцы, точка с запятой завершает команду. На этом шаге таблицы пока пустые. Далее собираем функции в service.py; наполнение будет после них.
