Этот документ содержит все строки двух дополнительных Python-файлов. Помощник паролей можно просто взять готовым: разрабатывать алгоритм шифрования не требуется. Если собираете его вручную, следуйте зелёным строкам ниже.

## settings.py

Создайте пустой settings.py. Данные ниже — образец: вместо ВАШ_ПАРОЛЬ напишите свой пароль PostgreSQL. Он не публикуется в репозитории и отличается от паролей пользователей приложения.

```diff

```

### Действие 2. Файл settings.py: допишите зелёную строку

```diff
 # Создайте копию с именем settings.py и укажите свой пароль PostgreSQL.
+DB = dict(dbname="final_up_beginner", user="postgres", password="ВАШ_ПАРОЛЬ",
```

DB — словарь подключения. dbname — имя нашей базы, user — пользователь сервера, password — его пароль. Запись продолжается в следующей строке.

### Действие 3. Файл settings.py: допишите зелёную строку

```diff

+          host="localhost", port=5432, connect_timeout=5)
```

host — адрес сервера, port — порт PostgreSQL, connect_timeout — ожидание соединения в секундах. Закрываем скобку словаря.
