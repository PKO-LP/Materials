# Собираем систему тестирования по шагам

Эта папка теперь относится к финальному заданию «Система тестирования учащихся». Предыдущая сборка склада заменена сборкой тестирования.

**Выбор «Ваш преподаватель» не нужен.** В системе один общий тест из пяти вопросов. Все преподаватели редактируют общий тест и видят результаты всех учеников. Ученик не может открыть редактор или статистику. Регистрация обеих ролей остаётся.

## Порядок сборки

Создайте рядом с этими материалами папку своей программы, например testing_app. Все Python-файлы ниже должны лежать в ней, рядом друг с другом. Не смешивайте их с файлами примера склада.

1. Откройте 01_База_и_настройки.md: создайте базу, таблицы и settings.py, положите рядом password_tools.py.
2. Откройте 02_Работа_с_данными.md: последовательно соберите service.py.
3. Откройте 03_Начальные_данные.md: соберите и выполните seed.py, чтобы появились аккаунты и вопросы.
4. Откройте 04_Окна_Tkinter.md: последовательно соберите app.py.
5. Откройте 05_Проверка.md: проверьте все действия и сохранение после перезапуска.
6. Если непонятно слово или параметр, посмотрите 06_Словарь.md.

В каждой инструкции указаны имя файла и место добавления. Код показан по одной строке. Это продолжения одного файла: добавляйте строки сверху вниз, сохраняя отступы. Не запускайте отдельную строку def или незаконченный if. В конце каждого целого раздела можно проверить синтаксис; приложение запускайте после завершения сборки app.py.

## Как связаны части

app.py показывает поля и кнопки. Нажатие кнопки вызывает функцию service.py. Эта функция проверяет роль, читает или сохраняет PostgreSQL и возвращает результат. app.py показывает его в виджетах.

Вход → кабинет по роли → преподаватель редактирует общий тест или ученик отвечает → завершение сохраняет попытку и пять ответов → преподаватель открывает статистику и подробности.

Количество верных ответов вычисляется в Python после проверки всех пяти выборов. Пока счётчик увеличивается, в БД ничего не записывается. Затем попытка и все ответы сохраняются вместе. Даже ноль правильных — завершённый результат, который нужно сохранить.

Правильные ответы берутся из снимка при начале попытки. Снимок сохраняется с результатом, поэтому изменение общего теста не меняет старые оценки и начатую версию теста.

SQL в этой сборке не использует JOIN: для статистики сначала читается список учеников, затем попытки каждого, затем ответы выбранной попытки. Для небольшого учебного примера это понятная последовательность SELECT.

Обычные функции, без собственных классов. Вспомогательный password_tools.py можно взять готовым: он защищает пароли хешем с солью. Действующий settings.py вы создаёте сами с паролем своего сервера.
