# Простая система тестирования — сборка для начинающих

Эта инструкция соответствует упрощённому финальному ТЗ. Ученик проходит пять вопросов и видит свои оценки. Преподаватель видит все результаты. При регистрации выбирают только роль, выбирать преподавателя не нужно.

**В программе один основной файл app.py.** Дополнительно рядом лежат готовый помощник password_tools.py и ваши настройки settings.py. Редактора вопросов, истории версий и сложных связей таблиц нет.

## Идём по порядку

Создайте отдельную папку testing_app. Все Python-файлы должны лежать рядом в ней.

1. 01_Подготовка.md — проверяем программы, создаём настройки, три таблицы и пять вопросов.
2. 02_Вход_и_регистрация.md — создаём app.py, добавляем подключение, вход и регистрацию.
3. 03_Тест_и_оценка.md — в тот же app.py добавляем кабинет, пять вопросов и подсчёт.
4. 04_Результаты_и_запуск.md — в тот же app.py добавляем таблицу результатов и запуск окна.
5. 05_Проверка_и_словарь.md — запускаем, проверяем и разбираем непонятные слова.

В документах 02–04 каждая рамка — следующая строка **одного и того же app.py**. Добавляйте её вниз после предыдущей, сохраняя пробелы слева. Номера шагов не пишите в код. Не запускайте отдельные строки с def, if и for: им нужны следующие строки с отступами.

Окно появится после завершения документа 04. До этого можно проверять синтаксис законченных функций через python3 -m py_compile app.py. Отсутствие ошибки не означает, что уже собрана вся программа.

Когда всё соберёте: создайте через интерфейс преподавателя и ученика, войдите учеником, пройдите тест, посмотрите оценку. Затем войдите преподавателем и откройте все результаты.

## Как всё соединяется

Нажатие кнопки вызывает функцию Python. Она читает поля, вызывает функцию запрос и получает данные PostgreSQL. Затем Python показывает их в виджетах. Сравнение ответов увеличивает счётчик в памяти; INSERT сохраняет итог после завершения теста.

Вопросы уже заполнены SQL-командой. Тест один для всех. Чтобы повторить пример, не нужно разрабатывать свою структуру базы: три таблицы и команды уже даны ниже по шагам.
