# 6. Словарь к сборке

## Python и данные

- `import` подключает модуль, `from ... import` — выбранные имена. `as` задаёт короткое имя. В этой сборке `db` — модуль service, `tk` — tkinter.
- `def` объявляет функцию, скобки содержат параметры, двоеточие начинает тело с отступом. Вложенная функция видит локальные переменные внешней функции: так обработчик кнопки помнит свои поля.
- `=` присваивает, `==` сравнивает, `!=` означает «не равно». `not` — отрицание, `or` — хотя бы одно условие, `and` — оба. `is None` проверяет отсутствие значения. `True` и `False` — логические значения.
- `if / elif / else` выбирают ветку. `return` заканчивает функцию. `raise ValueError` прекращает неверную операцию, чтобы обработчик показал предупреждение. `try / except / finally` выполняют действие, обрабатывают ошибку и завершающее действие.
- `global` разрешает присваивать новые значения общей переменной. Например, `session` хранит вошедшего пользователя, `cabinet` — текущее окно кабинета. Это обычные переменные, не классы.
- `dict(...)` или `{}` — словарь: `row['role']` читает значение по имени. `[]` — список, `append` добавляет элемент, `clear` очищает. `update` добавляет/обновляет пары словаря. `del` удаляет ключ.
- `row_factory=dict_row` задаёт формат ответа psycopg: каждая строка — словарь, поэтому пишем `row['id']`, а не `row[0]`. Это настройка готовой библиотеки, писать свой класс не нужно.
- `len` считает элементы. `any` проверяет, есть ли хотя бы одно истинное условие. Выражение в квадратных скобках с `for` собирает новый список; в фигурных — множество уникальных значений, если не указаны пары ключ/значение.
- `enumerate(...,1)` даёт пары «номер с единицы, элемент». `zip` объединяет списки по порядку; перед оцениванием длины и допустимые значения уже проверены.
- `*variants` раскрывает четыре варианта в последовательность аргументов или кортежа; `**DB` раскрывает словарь как именованные параметры подключения.
- `str` получает текст. `strip` убирает пробелы по краям. `casefold` приводит логин к единому регистру. `get` у Entry/IntVar читает значение. Пароль через strip не пропускаем, чтобы не менять его содержание.
- `f"...{значение}..."` вставляет значение в текст. `+` у строк соединяет их. `+= 1` увеличивает число на один.
- `list(...)` создаёт отдельный список. `[0]` берёт первый элемент; здесь `page=[0]` и `completed=[False]` позволяют вложенным обработчикам менять состояние без global.
- `questions[:] = ...` заменяет содержимое существующего списка. Остальные обработчики видят этот же обновлённый список вопросов.
- `uuid4()` создаёт уникальный UUID. Для новой попытки он новый, при повторном завершении остаётся прежним.
- `timezone(timedelta(hours=3))` задаёт UTC+3, `astimezone` переводит время в этот пояс, `strftime` форматирует его. `%d.%m.%Y %H:%M:%S` — день, месяц, год, часы, минуты, секунды.
- `__name__ == '__main__'` означает прямой запуск файла. При импорте service.py функции только определяются, окно само не создаётся.

## PostgreSQL и psycopg

- `SELECT` читает, `INSERT INTO ... VALUES` добавляет, `UPDATE ... SET ... WHERE` меняет существующую строку. `FROM` задаёт таблицу; `WHERE` отбирает нужные записи; `ORDER BY` сортирует. `DESC` — по убыванию; без него используется возрастание.
- `RETURNING id` возвращает ID добавленной/изменённой строки. `ON CONFLICT ... DO NOTHING` пропускает повтор ключа. При завершении попытки после этого отдельно читается уже сохранённый результат.
- `COUNT(*)` считает строки. `lower(login)` приводит текст к нижнему регистру. Полные определения типов и ограничений находятся в 01_База_и_настройки.md.
- `%s` — место значения в запросе psycopg. Значения передаются отдельно, например `(user_id,)`; запятая создаёт кортеж из одного элемента. Имена таблиц через %s не передаются. Не вставляйте пользовательский ввод в SQL через f-строки.
- `connect` подключается, `cursor` создаёт исполнителя команд, `execute` выполняет команду, `fetchone` читает строку или None, `fetchall` — список строк. `conn.execute` — сокращённая запись выполнения команды через соединение.
- `with` у соединения psycopg сохраняет транзакцию при успехе, отменяет при исключении и закрывает соединение. Все INSERT внутри одного внешнего with относятся к одной транзакции. Перехватываем ошибку снаружи, чтобы откат произошёл.
- `psycopg.errors.UniqueViolation` — повтор уникального ключа; `psycopg.Error` — общая ошибка драйвера/БД. `from None` у raise скрывает лишнюю цепочку технических сообщений для понятной ошибки повтора логина.
- Снимок — обычная сохранённая копия текста вопроса, вариантов и правильного номера. Он не требует JOIN: при старте всё читается из одной questions, а при завершении копируется в answers.

## Окна и размещение

- `tk.Tk()` создаёт единственное главное окно, `tk.Toplevel(root)` — дополнительное. `title` задаёт заголовок; `geometry('500x440')` — ширину и высоту в пикселях.
- `withdraw` скрывает, `deiconify` возвращает, `destroy` уничтожает. `winfo_exists` проверяет существование; `winfo_children` перечисляет дочерние виджеты; `lift` поднимает окно; `focus_set` переводит курсор в поле.
- `protocol('WM_DELETE_WINDOW',logout)` назначает функцию крестику. `mainloop()` один раз в конце app.py запускает цикл событий. Без него приложение завершится без рабочего ввода.
- `Label` — надпись; `Entry` — ввод; `Frame` — группа; `Button` — кнопка; `Combobox` — список; `Radiobutton` — один из вариантов; `Treeview` — таблица; `ScrolledText` — текст с прокруткой.
- Первый аргумент виджета — родитель. `text` — надпись, `font` — шрифт и размер, `wraplength` — ширина переноса, `width` у Entry — символы; `padding` — внутренний отступ Frame.
- `command=функция` передаёт действие без немедленного вызова. `lambda: move(1)` создаёт маленький обработчик, вызывающий move с аргументом. `safe(действие,окно)` возвращает обработчик с обработкой ошибок, а не выполняет действие сразу.
- `show='*'` скрывает пароль. `state='readonly'` запрещает произвольный ввод в Combobox, `disabled` выключает действие, `normal` включает. `config/configure` меняют свойства уже созданного виджета.
- `IntVar(value=0)` хранит выбор; у четырёх Radiobutton одного вопроса общая `variable`, разные `value` от 1 до 4. У каждого нового вопроса своя IntVar.
- `Combobox.set` задаёт текст, `current` — индекс выбранного элемента (с нуля), `bind('<<ComboboxSelected>>',функция)` вызывает функцию после выбора. Аргумент `event=None` позволяет вызвать её и вручную без события.
- `Entry.delete(0,tk.END)` очищает поле. `insert(0,текст)` добавляет в начало. `tk.END` — конец строки/таблицы/текста.
- `pack` размещает виджет: `side` — сторона, `fill='x'/'y'/'both'` — растяжение; `expand=True` отдаёт свободное место; `padx/pady` — отступы. Кортеж pady задаёт отдельные отступы сверху и снизу. `anchor='w'` прижимает к левому краю.
- `grid` размещает по ячейкам: `row`, `column` — номера с нуля; `sticky='nsew'` растягивает во всех направлениях. `rowconfigure/columnconfigure(...,weight=1)` разрешают строке/столбцу растягиваться.
- Не используйте pack и grid для детей одного родителя. Здесь Frame внутри окна может быть размещён pack, а дети этого Frame — grid: это разные родители.

## Таблица, прокрутка и сообщения

- `columns` задаёт внутренние имена колонок, `show='headings'` скрывает служебную колонку дерева, `height` — количество видимых строк. `heading` задаёт надпись; `column` — ширину в пикселях; `stretch=False` сохраняет заданную ширину.
- `Treeview.insert('',tk.END,values=...)` добавляет строку верхнего уровня в конец. Возвращённый ID строки сохраняется в mapping, чтобы находить UUID нужной попытки.
- `get_children` возвращает ID строк, `selection` — выбранные ID, `delete` очищает только виджет. Это не удаляет записи PostgreSQL.
- `Scrollbar` получает `orient` и `command=table.yview/xview`. Обратная настройка `yscrollcommand/xscrollcommand=...set` синхронизирует ползунок. Нужны обе стороны связи.
- `ScrolledText.insert(tk.END,текст)` добавляет разбор; `state='disabled'` запрещает редактировать показанные результаты; `wrap='word'` переносит текст по словам.
- `messagebox.showinfo/showwarning/showerror` показывают сообщение, предупреждение или ошибку. Первые два аргумента — заголовок и текст; `parent` — родительское окно.
