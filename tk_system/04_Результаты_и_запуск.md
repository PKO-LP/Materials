## Проверка

Сохраните файл. Выполните в терминале из папки testing_app:

```sh
python3 -m py_compile app.py
```

Если ошибок нет, запись кода корректна. Теперь запустите:

```sh
python3 app.py
```

Ожидается окно входа. Переходите к 05_Проверка_и_словарь.md.
