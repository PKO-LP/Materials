# 1. Подготовка

## Где что писать

Команды python3 выполняйте в терминале. SQL — в Query Tool pgAdmin. Код приложения — в редакторе, в app.py. Сначала создайте папку testing_app и откройте её в редакторе.

## Проверяем установленное

Каждую команду выполняйте отдельно:

```sh
python3 --version
```

Показывает версию Python. Если Python отсутствует, сначала установите его.

```sh
python3 -m tkinter
```

Должно появиться маленькое тестовое окно. Закройте его. Если tkinter отсутствует, нужен Python с Tcl/Tk.

```sh
python3 -c "import psycopg; print(psycopg.__version__)"
```

Если появилась версия, библиотека уже есть. Только если написано, что psycopg отсутствует, выполните:

```sh
python3 -m pip install "psycopg[binary]>=3.2,<4"
```

Для обычного запуска приложения повторно ничего устанавливать не нужно.

## Два готовых файла

1. Скопируйте password_tools.py в testing_app. Это готовый помощник: создать_хеш защищает пароль, проверить_пароль сравнивает введённый пароль с сохранённым хешем. Его не нужно переписывать.
2. Создайте settings.py в testing_app по документу 06_Готовые_помощники.md. Можно вместо этого скопировать settings_example.py и назвать копию settings.py. Образец можно оставить. В settings.py вместо ВАШ_ПАРОЛЬ укажите свой пароль PostgreSQL. Программа обращается именно к settings.py.

DB — словарь настроек: dbname — база, user — пользователь сервера, password — пароль сервера, host — адрес, port — порт, connect_timeout — сколько секунд ждать соединение. Пароль PostgreSQL и пароль аккаунта приложения — разные вещи.

## SQL собираем в файлах

Создавайте перечисленные .sql файлы в папке testing_app. В каждой рамке дописывайте только зелёную строку без знака +. Обычные строки уже есть: они показывают место продолжения. Наберите команду до точки с запятой, затем откройте её в Query Tool и выполните целиком. Нельзя выполнять отдельно строку описания столбца.

## 00_create_database.sql — создаём базу

Создайте пустой файл 00_create_database.sql. Запрос выполняется в Query Tool базы postgres.

### Действие 1. Файл 00_create_database.sql: допишите зелёную строку

```diff
+CREATE DATABASE final_up_beginner;
```

CREATE — создать, DATABASE — базу данных. final_up_beginner — имя нашей базы. Выполните эту команду один раз в Query Tool базы postgres.

## 02_questions.sql — пять вопросов

Создайте пустой файл 02_questions.sql. Строки VALUES и все пять вопросов относятся к одному запросу. Выполните его только после строки ON CONFLICT ... ;.

### Действие 1. Файл 02_questions.sql: допишите зелёную строку

```diff
+INSERT INTO questions (id, question, answer_1, answer_2, answer_3, answer_4, correct)
```

INSERT INTO добавляет строки в указанную таблицу. Имена в скобках задают порядок значений. Запрос пока не выполняйте: ниже добавим VALUES и все вопросы.

### Действие 2. Файл 02_questions.sql: допишите зелёную строку

```diff

```

VALUES означает «дальше идут значения». Каждый следующий набор в скобках — один вопрос.

### Действие 3. Файл 02_questions.sql: допишите зелёную строку
