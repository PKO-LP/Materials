# 1. Подготовка

## Где что писать

Команды python3 выполняйте в терминале. SQL — в Query Tool pgAdmin. Код приложения — в редакторе, в app.py. Сначала создайте папку testing_app и откройте её в редакторе.

## Проверяем установленное

Каждую команду выполняйте отдельно:

```sh
python3 --version
```

Показывает версию Python. Если Python отсутствует, сначала установите его.

```sh
python3 -m tkinter
```

Должно появиться маленькое тестовое окно. Закройте его. Если tkinter отсутствует, нужен Python с Tcl/Tk.

```sh
python3 -c "import psycopg; print(psycopg.__version__)"
```

Если появилась версия, библиотека уже есть. Только если написано, что psycopg отсутствует, выполните:

```sh
python3 -m pip install "psycopg[binary]>=3.2,<4"
```

Для обычного запуска приложения повторно ничего устанавливать не нужно.

## Два готовых файла

1. Скопируйте password_tools.py в testing_app. Это готовый помощник: создать_хеш защищает пароль, проверить_пароль сравнивает введённый пароль с сохранённым хешем. Его не нужно переписывать.
2. Скопируйте settings_example.py в testing_app. Сделайте копию и назовите settings.py. Образец можно оставить. В settings.py вместо ВАШ_ПАРОЛЬ укажите свой пароль PostgreSQL. Программа обращается именно к settings.py.

DB — словарь настроек: dbname — база, user — пользователь сервера, password — пароль сервера, host — адрес, port — порт, connect_timeout — сколько секунд ждать соединение. Пароль PostgreSQL и пароль аккаунта приложения — разные вещи.

## Создаём базу

В pgAdmin подключитесь к серверу, откройте Query Tool базы postgres и один раз выполните:

```sql
CREATE DATABASE final_up_beginner;
```

CREATE означает «создать», DATABASE — «базу данных». final_up_beginner — её имя. Точка с запятой завершает команду. Если база уже есть, повторное создание пропустите.

Обновите список баз и откройте Query Tool **final_up_beginner**. Проверьте:

```sql
SELECT current_database();
```

SELECT получает значение, current_database() возвращает имя открытой базы. Должно быть final_up_beginner.

## Создаём три таблицы

Выполняйте каждый следующий блок отдельно, целиком:

```sql
CREATE TABLE IF NOT EXISTS users (
    login TEXT PRIMARY KEY,
    password_hash TEXT NOT NULL,
    role TEXT NOT NULL
);
```

```sql
CREATE TABLE IF NOT EXISTS questions (
    id INTEGER PRIMARY KEY,
    question TEXT NOT NULL,
    answer_1 TEXT NOT NULL,
    answer_2 TEXT NOT NULL,
    answer_3 TEXT NOT NULL,
    answer_4 TEXT NOT NULL,
    correct INTEGER NOT NULL
);
```

```sql
CREATE TABLE IF NOT EXISTS results (
    id SERIAL PRIMARY KEY,
    student_login TEXT NOT NULL,
    score INTEGER NOT NULL,
    grade INTEGER NOT NULL
);
```

CREATE TABLE создаёт таблицу. IF NOT EXISTS означает «если ещё не существует». Скобки содержат столбцы, запятые их разделяют.

TEXT — текст, INTEGER — целое число, SERIAL — автоматически выдаваемое целое число. PRIMARY KEY — уникальное значение, по которому различают строки; NOT NULL — значение обязательно.

users хранит login — логин, password_hash — защищённый пароль, role — роль. Логин здесь ключ: повтор не сохранится.

questions хранит id — номер вопроса, question — его текст, answer_1–answer_4 — четыре текста вариантов, correct — номер правильного от 1 до 4.

results хранит id — номер результата (появляется автоматически), student_login — логин ученика, score — сколько ответов верно, grade — оценку.

## Добавляем вопросы

Выполните этот запрос одной командой:

```sql
INSERT INTO questions (id, question, answer_1, answer_2, answer_3, answer_4, correct)
VALUES
(1, 'Какой запрос читает данные?', 'SELECT', 'INSERT', 'UPDATE', 'CREATE', 1),
(2, 'Какое слово указывает таблицу в SELECT?', 'ORDER', 'FROM', 'VALUES', 'SET', 2),
(3, 'Какой запрос добавляет строку?', 'DROP', 'SELECT', 'INSERT', 'WHERE', 3),
(4, 'Какой тип хранит целое число?', 'DATE', 'TEXT', 'NUMERIC', 'INTEGER', 4),
(5, 'Как сортировать по возрастанию?', 'ASC', 'DESC', 'NULL', 'CHECK', 1)
ON CONFLICT (id) DO NOTHING;
```

INSERT INTO означает «добавить в таблицу», список в скобках задаёт порядок столбцов. VALUES начинает значения. Каждый набор в скобках — один вопрос; строки разделены запятыми. Тексты записываются в одинарных кавычках, числа — без кавычек.

Например, последняя 1 в первом вопросе означает, что правильный вариант — answer_1. ON CONFLICT (id) DO NOTHING позволяет повторить заполнение без дубликатов: существующий номер пропускается.

Проверьте отдельно:

```sql
SELECT id, question, correct FROM questions ORDER BY id;
```

FROM указывает таблицу, ORDER BY упорядочивает строки по номеру. Должны быть пять вопросов. Пользователей пока нет: позже создадим их кнопкой регистрации.
