## Проверка готовой части

Сохраните файл. Он импортирует уже собранный service.py и использует settings.py и password_tools.py из этой же папки.

```sh
python3 seed.py
```

Ожидается сообщение о четырёх аккаунтах и общем тесте. Логины: teacher с ролью «Преподаватель», student1, student2, student3 с ролью «Ученик». Пароль каждого: Demo2026! Для обычного запуска повторно наполнять базу не нужно.

В Query Tool базы final_up_shared отдельно проверьте:

```sql
SELECT login, role FROM users ORDER BY login;
```

```sql
SELECT position, question_text FROM questions ORDER BY position;
```

Должны появиться четыре пользователя и пять вопросов. Пароли и хеши в результат проверки выводить не нужно. Затем переходите к app.py.
